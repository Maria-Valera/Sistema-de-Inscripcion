# /cerrar-dia
Descripcion: cierre de la jornada de un modulo.
1. Ejecuta las pruebas del modulo indicado (tests/Feature/Notas/{Modulo}).
2. Ejecuta php artisan notas:verificar-esquema (si existe).
3. Muestra git status y lista los archivos modificados FUERA de la carpeta del modulo. Si hay alguno, detente y explica por que.
4. Resume en 5 lineas: que se hizo, que falta, decisiones tomadas.
5. Propon el mensaje de commit con prefijo [Mxx] y espera mi confirmacion antes de hacer commit.
