# /nuevo-modulo
Descripcion: crea la estructura de un modulo nuevo.
1. Pregunta el nombre del modulo si no lo indique.
2. Ejecuta php artisan notas:make-module {Nombre}.
3. Verifica que la ruta de ejemplo cargue y que las pruebas generadas pasen.
4. No modifiques nada fuera de app/Modules/Notas/{Nombre}.
